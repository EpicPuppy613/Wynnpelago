# APWorld Backwards Compatability

Wynnpelago's in-game tracker depends on an internal data file containing all the logic for all content in Wynncraft.
This data file changes over time to fix logic and other issues.
If playing on an __older__ version of the APWorld than this version of Wynnpelago was made for,
there could be potential inconsistencies in what is display on the in-game tracker, and what is actually in logic.
This can be fixed by using one of the following resource packs, depending on what version of the APWorld the multiworld was __generated__ with.
